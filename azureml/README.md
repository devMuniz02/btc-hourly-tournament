# Azure ML Assets

This folder contains the Azure Machine Learning v2 assets that turn the BTC direction project into an interview-ready MLOps portfolio implementation.

- `components/`: reusable Azure ML command components
- `environments/`: versioned runtime definition
- `pipelines/`: pipeline job YAML
- `endpoints/`: managed online endpoint and deployment templates
- `compute/`: sample AML compute definition
- `sample-request.json`: example request payload for real-time scoring demos
